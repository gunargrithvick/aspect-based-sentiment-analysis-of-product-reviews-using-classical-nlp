# System Design

## High-level flow

```text
Review text
    -> deterministic preprocessing
    -> CRF aspect extraction
    -> aspect-centered context construction
    -> TF-IDF transformation
    -> Linear SVM sentiment classification
    -> structured aspect-sentiment output
```

## Components

| Component | Responsibility |
|---|---|
| `dataset_loader.py` | Parse and validate SemEval XML annotations |
| `text_preprocessing.py` | Tokenization, normalization, lemmas, POS heuristics, and negation |
| `aspect_extractor.py` | CRF-based BIO sequence labeling and span reconstruction |
| `feature_engineering.py` | Aspect-centered context construction |
| `sentiment_classifier.py` | TF-IDF and Linear SVM sentiment prediction |
| `inference_pipeline.py` | Combine trained models for standalone prediction |
| `evaluation_metrics.py` | Calculate component and end-to-end metrics |

## Runtime interface

The command-line interface is:

```bash
python scripts/analyze_review.py --text "The display is bright, but the keyboard feels cheap."
```

The output is JSON so it can be read by a person or another local program. The project also provides a browser interface through FastAPI:

```text
Browser HTML/CSS/JavaScript
    -> POST /api/analyze
    -> FastAPI application
    -> existing classical NLP inference pipeline
```

The browser interface is a presentation layer for the NLP system; it does not add an LLM, generative model, or external API.

## Model files

The default runtime loads:

- `models/crf_aspect_extractor.joblib`
- `models/svm_sentiment_classifier.joblib`

These files are generated by the improved-model training script.
